# Learn the Algorithm

A scroll-driven field guide to how the X For You feed is assembled, ranked, filtered, and blended.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

Facts and default weights come from the public `xai-org/x-algorithm` repository (especially
`home-mixer/params/param.rs`) and its README, as documented in `/home/ubuntu/spec.md`. Production
values may differ because configuration and experiments can change them.
Learn how the x algorithm works.
